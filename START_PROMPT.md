# Start Prompt / Контекст на старт сессии

Этот файл - короткая стартовая сводка.  
Источник истины всегда в рабочих файлах ниже.

## 1) Обязательные файлы перед началом работы

1. `Assets/_Scripts/TODO_List.md`  
Главный backlog проекта (статусы, проценты готовности, приоритеты P0/P1/P2, регресс-чеклист).

2. `GPT_JOURNAL.md`  
Журнал контекста и изменений по сессиям (что сделано, почему важно, что осталось).

3. `Assets/Igrodelnya2.0/Localization/Reports/Localization_TODO.md`  
Отдельный backlog локализации и требования к процессу.

## 2) Базовые правила работы

- Все заметные изменения проходят через `TODO_List.md`.
- После заметного шага нужно обновить `GPT_JOURNAL.md` (дата/время, что изменено, почему важно, что осталось).
- Локализацию вести отдельно от общего TODO (в `Localization_TODO.md`).
- При изменении серверных контрактов синхронно обновлять клиент+сервер и явно фиксировать это в журнале.
- После серверных изменений напоминать команды деплоя:

```bash
cd /srv/farmgame
git pull
docker compose stop nginx certbot api
docker compose build api
docker compose up -d
```

## 3) Обязательные требования по локализации (для всех новых фич)

- Любой user-facing текст должен быть локализован (без hardcoded строк в UI/флоу).
- Для новых UI-строк добавлять ключи и значения минимум для RU/EN.
- Критично не допускать пустых отображаемых строк: при пустом значении нужен fallback.
- Для динамических строк нужен guard: missing key -> fallback текст + предупреждение в лог без спама.
- Перед релизом нужен smoke локализации (переключение языков и проверка ключевых экранов).

## 4) Рабочий ритуал на каждую новую сессию

1. Прочитать 3 файла из раздела "Обязательные файлы".
2. Уточнить текущий приоритет в `TODO_List.md` и взять задачу оттуда.
3. Выполнить изменения + ручной smoke по затронутому сценарию.
4. Обновить статусы в TODO, затем добавить запись в `GPT_JOURNAL.md`.
5. Если затронута локализация, обновить `Localization_TODO.md` и связанные отчеты/ключи.

## 5) Быстрая ссылка для следующего раза

Для старта новой сессии можно писать:  
"Используй контекст из `START_PROMPT.md` и работай по правилам из связанных TODO/Journal файлов."
