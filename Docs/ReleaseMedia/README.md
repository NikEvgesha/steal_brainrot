# Release Media

## Final files

- `Final/obby-zoo-icon-512.png` - final 512x512 store icon.
- `Final/obby-zoo-cover-800x470.png` - final 800x470 store cover.
- `Final/obby-zoo-icon-master.png` - high-resolution icon master.
- `Final/obby-zoo-cover-master.png` - high-resolution cover master.

The final images intentionally contain no text, platform logo or UI. This keeps them reusable across publishers and languages.

## Generation

Both masters were created with the built-in OpenAI image generation tool using the project's real tiger, wolf, egg and gameplay visuals as references.

### Icon direction

An expressive voxel tiger cub bursting from the game's green striped egg. The close crop, contrasting orange and green palette and simplified tropical background are designed to remain readable at small store-icon sizes.

### Cover direction

The player carries an egg through a bright tropical zoo while a second egg hatches between a tiger and a wolf. The conveyor and giraffe in the background communicate the collection and zoo-building loop without relying on text.

## Usage notes

- Submit the exact-size files from `Final`.
- Keep the master files for future crops and publisher-specific formats.
- Do not add small text to the icon.
- Add a title to the cover only when a publisher explicitly requires or allows it.
