## Контракт системы

- Каждое задание хранится отдельно по неизменяемому `stable_id`: статус, revision, прогресс, timestamps и флаг выданной награды.
- Перестановка заданий не сбрасывает выполненное. Переименование ID допускается только через явный alias/migration.
- Новый ID остаётся новым и для старого игрока. Если механика уже выполнена, задание показывается минимум на короткое время, затем воспроизводит анимацию завершения и выдаёт положенную награду.
- Scheduler выбирает задание по prerequisites, priority и собственному activation trigger, а не по сохранённому индексу.
- Skip удалён: случайно отказаться от задания и его награды нельзя.
- Активный текст находится справа сверху, симметрично валюте, сворачивается стрелкой влево и учитывает safe area.
- Подсказка может одновременно вести к основной цели и телепорту. Поддерживаются world-цели, UI-цели и подсветка объекта действия.
- Во время активной обязательной цепочки timed interstitial подавляется; после завершения действует grace-период 45 секунд.

Save schema: `4`. Pack: `core_v2`. Полная награда цепочки: `32` hard currency.

## Игровые сигналы и защита от крайних случаев

- Отдельные сигналы заведены для покупки/установки/ускорения/вылупления яйца, album rewards, покупки BigPet, покупки еды, кормления, территории и улучшения конвейера.
- Tutorial-цели ищутся только на локальной базе; уход на чужую локацию не позволяет завершить домашнее действие.
- Убрано прежнее бесплатное стартовое яйцо и искусственный пятисекундный таймер: используются реальные цена и длительность.
- Для первого tutorial-яйца гарантируется понятный базовый результат без неудачного element/weight random.
- Награда защищена `completionRewardGranted`; повторный сигнал, restart или reconnect не выдаёт валюту второй раз.
- Старый `EndTutorial` мигрирует только известное завершённое задание движения; новые V2-ID проходят собственную проверку игровых фактов и остаются доступны старым игрокам.

## UI и локализация

- Prefab: `Assets/Resources/Tutorial/TutorialView.prefab`.
- Для задания без награды reward badge скрыт. Для наградного задания показываются иконка hard currency и сумма.
- После выполнения панель показывает локализованное «Задание выполнено», индикатор `OK` и pulse-анимацию до перехода дальше.
- Основная стрелка указывает на ближайшее допустимое действие; вторая голубая стрелка используется для альтернативного телепорта.
- `Tools/Tutorial V1/Synchronize RU-EN Localization` синхронизирует owned-ключи, а `Validate Setup` проверяет каталог, миграции, prefab и RU/EN.
