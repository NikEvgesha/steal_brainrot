# Настройка ClaimAllCoinsZone

## Что изменилось
- `ClaimAllCoinsZone` больше не сканирует всю сцену каждый рефреш через `FindObjectsByType<Brainrot/BigPetPoint>`.
- Теперь зона один раз собирает кэш источников дохода из заданного корня.
- Базовый сценарий: задаем один корневой объект в инспекторе, зона сама берет `FieldCell` и `BigPetPoint` под ним.

## Что настроить в сцене
1. Выбери объект с `ClaimAllCoinsZone`.
2. В блоке **Income Sources** укажи `Income Sources Root` на корень локальной базы (обычно `SceneAny` локального слота).
3. Оставь `Auto Discover Income Sources` включенным.
4. Если часть источников лежит вне корня, добавь их вручную в `Manual Income Cells` и/или `Manual Big Pet Points`.

## Настройка popup
1. Лучший вариант: проставить `Decision Popup` напрямую в инспекторе.
2. Если не проставлен, укажи `Popup Search Root` (обычно `GameCanvas`).
3. `Allow Global Popup Fallback` оставлен для совместимости: если локально popup не найден, используется старый глобальный поиск.

## По структуре
- Правильная зависимость: `ClaimAllCoinsZone -> источники дохода`.
- Не нужно прокидывать ссылку на зону в каждую `FieldCell`.
- В `FieldCell` добавлен `CurrentBrainrot`, поэтому зона работает без глобального поиска.

## Чек-лист проверки
1. Вход в зону без покупки forever: кнопка взаимодействия появляется.
2. Сбор через рекламу: собирает доход со всех локальных источников.
3. Покупка forever: кнопка скрывается, автосбор в зоне работает.
4. Доход удаленных баз не затрагивается.
5. В логе и профилировании нет повторяющихся глобальных `FindObjectsByType<Brainrot/BigPetPoint>` на каждом рефреше.
